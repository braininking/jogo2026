# OfertaRadar

Radar de ofertas, preços e produtos em alta.

## MVP
- Busca de produtos em tempo real via API pública do Mercado Livre.
- Radar inicial por categorias.
- Interface responsiva.
- Estrutura preparada para afiliados, histórico de preços e alertas.

## Próximas automações
1. Persistir histórico de preços.
2. Integrar links de afiliado autorizados.
3. Criar páginas SEO por produto/categoria.
4. Adicionar cron para atualização automática.
5. Comparar múltiplos marketplaces.

O site não inventa descontos: o percentual mostrado é calculado somente quando a API fornece preço original.
